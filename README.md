# tavern-forum-cyan

一个运行在 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 中的沉浸式世界社交论坛扩展。

它会把角色和故事世界组织成一套独立的社交网络：角色可以发帖、评论、转发、关注、私信并形成各自的社交记忆。论坛既能选择性读取酒馆内容，也能把选中的论坛动态注入主聊天，让论坛事件真正参与后续剧情。

> 项目仍在持续开发中。升级前建议先在插件的“我 → 数据”中导出备份。

## 功能概览（测试中）

### 社交论坛

- 首页包含“关注、推荐、最新、热门”四种信息流。
- 支持发帖、点赞、收藏、转发、引用、投票、话题、@提及和评论楼中楼。
- 帖子详情页可连续浏览评论；用户回复后可按需让 AI 继续跟帖。
- AI 角色也可以发布、评论和转发，旧帖的互动量会随论坛刷新自然变化。
- 搜索支持帖子、用户、话题、联系人和通知。
- 普通帖子可以自动清理或手动删除；收藏内容不会被自动清理。

### 角色、主页与私信

- 当前 Char 会自动建立为默认角色；其他动态作者只有生成人设后才进入角色库。
- 论坛角色可以引用酒馆 Char 或具体世界书条目作为人设资料；这与 SillyTavern 的 Character Lore 绑定是两个独立概念。
- 角色和用户均拥有独立主页，可设置头像、背景、简介、账号和关注关系。
- 图片支持本地导入、图床直链与内置随机头像。
- 用户可以和角色私信，也可以选择开启角色 A ↔ B 的保密私信。
- 私信中的发送与 AI 回复相互独立：发送消息不会自动调用 API。
- 可选择让已有角色主动关注并发送私信；主动私信可以和论坛刷新共用同一次 API 请求，不会额外调用一次。
- 支持回复、提及、点赞、关注、互关和系统通知，并可分别关闭通知类型。
- 支持关注、取消关注、静音和拉黑；关系可在“我 → 隐私与关系”集中管理。

### 可选世界模块

- 任务会进入“消息 → 委托”，由角色或神秘账号发来；接受、完成或失败都会保留记录。
- 旅伴是一个会自行外出、寄回见闻和带回小物件的宠物角色，可从私信列表进入它的小窝。
- 背包放在用户个人主页中，用于保存任务奖励、旅伴带回的物品和剧情道具。
- 运势可以使用完全本地的每日随机模式，不调用 API；也可以选择与论坛联动或独立生成。
- 健康事件使用独立的角色化医疗小场景，举报和裁决进入通知中心；所有模块都可单独关闭。
- 每个模块可选择“持续联动”“独立生成”或支持时的“本地随机”，并能设置发生概率和冷却时间。
- 支持未生成原因说明，以及单个模块配置的导入、导出和重置。

### 角色记忆与信息边界

- 每个角色维护独立社交记忆，包括公开发言、与用户的关系、社交状态、私信秘密、已知与未知事实，以及对其他角色的态度。
- 所有记忆字段都可以由用户手动修改。
- 事实和世界书条目可设为公开、指定角色可知、仅私信可用或禁止生成读取。
- 角色之间的私信不会注入公共正文，未参与私信的角色也不会读取其中的秘密。

### 酒馆内容读取

以下来源拥有互相独立的总开关：

- 酒馆正文
- User 人设
- Char 人设
- 世界书
- 酒馆当前预设

世界书和酒馆预设还可以精确选择到每一个条目：

- 当前 Char 在 SillyTavern 中绑定的“主要世界书”和“附加世界书”会被自动识别并显示。
- 角色世界书的条目列表默认折叠，需要时再展开。
- 其他世界书默认收进折叠选择器且不读取；手动打开某本书后，它才会进入条目配置列表。
- 每本世界书拥有单独的整书读取开关；关闭整书读取不会改变内部条目的勾选状态。
- 上述选择只控制论坛读取，不会修改 SillyTavern 原本的主要/附加世界书绑定。
- 插件只读取酒馆预设的副本，不会修改酒馆中的原始条目；预设读取默认关闭。

### 生成、注入与 API

- 默认可直接使用 SillyTavern 当前连接和当前模型。
- 可以保存并自由切换多套 OpenAI Chat Completions 兼容配置。
- 独立配置支持温度、最大输出和自定义额外参数；点号键可建立嵌套参数。
- 每次论坛生成最多调用一次文本 API；模型格式异常时优先在浏览器本地整理。
- 持续联动的任务、旅伴、背包、健康、管理事件和主动私信会并入同一次论坛请求；独立模式才使用模块自己的 API 与 RPM 限制。
- 帖子、初始评论和后续 AI 跟帖数量均可设置最少值与最多值。
- 可选择是否在新的 Char 正文生成后自动刷新论坛，开场白不会触发。
- 每篇帖子都能单独决定是否注入主聊天；设置页会显示当前注入 Token 数量。
- 论坛生成使用宽松的数据区格式，数据区外的模型说明或推理内容不会显示在帖子里。
- 原始输出、接口推理字段和真正的错误会保存在“我 → 运行后台”，不会进入正文注入。
- 自动生成成功只在插件内部提示，不弹出 SillyTavern 的成功通知。

### 自动化与剧情安全

- 可以设置安静时段：暂停自动生成，或继续生成但暂时静音通知。
- 剧情强度可设为温和、平衡或强烈，并限制严重事件连续出现的次数和冷却时间。
- 可以直接禁止永久死亡、不可逆伤残、严重疾病、破产、骗局或永久任务失败；被禁止的事件会在本地丢弃，不会先弹窗询问，也不会因此再次调用 API。
- 插件内置提示词可分别编辑，并可单独恢复某一条内置提示词。
- 设置页支持搜索，例如输入“私信”可以直接定位相关配置。

### 图片与外观

- 帖子和评论都可以带图，但不会强制每篇内容生成图片。
- 可以单独配置生图 API；未配置时可选择使用中文文字画面描述代替图片。
- 支持自定义论坛名称、图标、字体、主题颜色和区域颜色。
- 支持论坛壁纸、帖子卡片透明度、毛玻璃效果以及完整的自定义 CSS。
- 悬浮入口可以关闭、更换图片并拖动位置。
- 布局会按照可用宽度自动适配桌面、窄窗口和手机端。

## 安装

### 使用扩展管理器

在 SillyTavern 中打开“扩展 → 安装扩展”，粘贴下面的 Git 仓库地址：

```text
https://github.com/jiucyan/tavern-forum-cyan
```

确认安装后刷新扩展，并使用 `Ctrl + F5` 强制刷新页面。仓库根目录包含 SillyTavern 所需的 `manifest.json`，可以直接通过链接安装，不需要下载压缩包。

### 手动安装

下载项目并解压，将整个 `tavern-forum-cyan` 文件夹放到当前 SillyTavern 用户的扩展目录：

```text
SillyTavern/data/default-user/extensions/tavern-forum-cyan/
```

文件夹内应直接包含：

```text
manifest.json
index.js
style.css
src/
```

不要在外面再套一层同名文件夹。完成后重启 SillyTavern，或在扩展管理页面刷新扩展。

## 初次使用

1. 打开一个角色聊天。
2. 从扩展菜单进入“打开微坛”，或点击悬浮入口。
3. 在“设置中心 → 正文联动”分别选择主聊天可读取的论坛内容，以及论坛生成可读取的酒馆资料。
4. 当前 Char 的主要/附加世界书会自动显示且条目默认折叠；其他书需要先从“其他世界书”中手动打开。
5. 在“我 → API”保留“酒馆当前连接”，或新增自己的独立 API 配置。
6. 返回首页，点击“刷新”生成第一批动态。

默认文本 API 为“酒馆当前连接”，无需再次填写地址、密钥或模型。思考模型可能需要更高的最大输出额度，可以在“我 → API”中调整。

## 数据与隐私

公开仓库中的源码不包含开发者的个人邮箱、本机用户目录、私人账号、API Key、访问令牌或预设的私人 API 服务地址。文本与生图接口的默认地址和密钥均为空，由使用者自行配置。

- API Key 默认只保留在当前页面会话；只有主动开启“记住 API Key”后才会写入 SillyTavern 扩展设置。
- API Key 只会随对应生成请求发送至使用者选择的服务。
- 帖子、评论、角色、私信、通知和关系数据保存在当前聊天的元数据中，不同聊天相互独立。
- 本地头像、背景和壁纸保存在浏览器的 LocalForage 存储中。
- 图床直链会在显示图片时连接对应的外部站点，请只使用自己信任的地址。
- “运行后台”可能包含模型原始输出、故事正文片段或接口错误信息。提交 Issue 时请先检查并隐去自己的剧情与服务信息。
- 删除浏览器站点数据、清空聊天元数据或更换浏览器环境可能导致本地数据丢失，重要数据请提前导出。

## 图片说明

- 图床地址必须是可以直接打开图片的 `http` 或 `https` 链接，而不是图片所在的网页。
- 本地图片只保存在当前浏览器环境，不会自动同步到其他设备。
- 删除本地头像库项目时，相应的本地图片数据也会被删除。
- 未配置生图 API 时，可以开启“无 API 时显示文字配图”；文字画面描述会强制使用中文。
